public class Assert {
    public static void assertTrue(String message, Boolean condition){
        if (!condition){
            fail(message);
        }
    }
    public static void assertTrue(Boolean condition){
        assertTrue(null, condition);
    }
    public static void assertFalse(String message, Boolean condition){
        assertTrue(message, !condition);
    }
    public static void assertFalse(Boolean condition){
        assertFalse(null, condition);
    }
}

public class Quadratic{
    public static double root1(double a,double b,double c){
        double determinant=determinant(a,b,c);
        return (-b+Math.sqrt(determinant))/(2*a);
    }
    public static double root2(int a,int b int c){
        double determinant=determinant(a,b,c);
        return (-b+Math.sqrt(determinant))/(2*a);
    }
    public static double determinant(double a,double b,double c){
        return (b*b–4*a*c);
    }
}

Sua empresa foi contratada para desenvolver um grande projeto.
Para o sucesso do projeto, será necessário contratar alguns colaboradores, principalmente na área de
implementação.
Defina algumas regras de equipes, tais como:
- nomes significativos
- métodos e funções
- formatação
Para cada item acima, deve ter no mínimo 3 regras ou restrições:

-nomes significativos:
1- utilizar estilo camelCase;
2- sem codficaçao na nomenclaura de variaveis;
3- não reutilizar o mesmo nome entre variaveis.

-metodos e funcoes:
1- Escrever no máximo 40 carácteres por variavel;
2- Criar funções diretas e objetivas;
3- evitar repetições.

-formatação
1- As variáveis devem-se declarar no início das classes.
2- Na formatação Vertical escreva classes com no máximo 500 linhas;
3- Na formatação horizontal não coloque espaços entre nomes das funções e os parênteses de abertura.
